# Learning Log

Учебный проект по разработке веб-приложений на Python и Django.

**Learning Log** — веб-журнал обучения, позволяющий пользователям регистрироваться, создавать темы для изучения и добавлять записи к каждой теме.

## Используемые технологии

- **Python** 3.12.14
- **Django** 6.1.1
- **СУБД** SQLite
- **Оформление** Bootstrap 4.6.2
- **Веб-сервер** Gunicorn
- **Контейнеризация** Docker и Docker Compose

## Возможности приложения

- Регистрация новых пользователей.
- Авторизация и выход из учётной записи.
- Создание и просмотр тем для изучения.
- Добавление записей к выбранным темам.
- Редактирование существующих записей.
- Разделение данных между пользователями: каждый пользователь работает со своими темами и записями.
- Административная панель Django.

## Запуск проекта на локальном компьютере (Windows)

### 1. Необходимые программы

Перед запуском необходимо установить:
- Git;
- Docker Desktop.

После установки необходимо запустить Docker Desktop.

### 2. Получение проекта

Открыть PowerShell и выполнить:

```powershell
git clone https://github.com/cookielover2008/Learning_log
```

Перейти в папку проекта:

```powershell
cd Learning_log
```

### 3. Настройка переменных окружения

В корневой папке проекта создать файл `.env` со следующим содержимым:

```env
DJANGO_SECRET_KEY=replace-with-a-long-random-secret
DJANGO_DEBUG=False
DJANGO_ALLOWED_HOSTS=localhost,127.0.0.1
DJANGO_CSRF_TRUSTED_ORIGINS=http://localhost:8000
SQLITE_PATH=/app/data/db.sqlite3
APP_BIND_IP=127.0.0.1
APP_PORT=8000
```

Секретный ключ рекомендуется заменить на собственный случайный ключ.

### 4. Запуск приложения

В PowerShell выполнить команду:

```powershell
docker compose up -d --build
```

Docker автоматически выполнит следующие действия:

1. Соберёт образ приложения.
2. Создаст и запустит контейнер.
3. Применит миграции базы данных.
4. Соберёт статические файлы Django.
5. Запустит веб-сервер Gunicorn.

Для проверки состояния контейнера выполнить:

```powershell
docker compose ps
```

Контейнер должен иметь статус `Up` и `healthy`.

### 5. Открытие приложения

После успешного запуска открыть браузер и перейти по адресу:

http://localhost:8000/

### 6. Создание администратора

Для создания административной учётной записи выполнить:

```powershell
docker compose exec web python manage.py createsuperuser
```

Далее необходимо указать имя пользователя, адрес электронной почты и пароль.

Административная панель Django доступна по адресу:

http://localhost:8000/admin/

Для обычной работы с приложением можно зарегистрировать отдельную учётную запись через кнопку Register.

## Проверка функциональности

После открытия приложения можно выполнить следующие действия:

1. Зарегистрировать нового пользователя.
2. Войти в созданную учётную запись.
3. Открыть раздел Topics.
4. Создать новую тему.
5. Открыть созданную тему.
6. Добавить запись к теме.
7. Изменить существующую запись.
8. Выйти из учётной записи и войти повторно, чтобы проверить сохранение данных.

## Полезные команды Docker

Проверка состояния контейнеров:

```powershell
docker compose ps
```

Просмотр логов приложения:

```powershell
docker compose logs -f web
```

Перезапуск контейнера:

```powershell
docker compose restart web
```

Пересборка и запуск приложения:

```powershell
docker compose up -d --build
```

Остановка приложения:

```powershell
docker compose down
```

## Хранение данных

База данных SQLite находится внутри контейнера по адресу `/app/data/db.sqlite3`.

Для сохранения данных используется именованный Docker-том `learning_log_data`.

При обычной остановке и пересоздании контейнера данные пользователей, темы и записи сохраняются.

**Важно:** команда `docker compose down -v` удаляет том вместе с базой данных. Использовать её без необходимости не рекомендуется.

## Дополнительная информация

Файл `.env` содержит индивидуальные настройки проекта и не загружается в репозиторий GitHub.

При первом запуске проекта на новом компьютере необходимо создать собственную административную учётную запись с помощью команды `createsuperuser`.
